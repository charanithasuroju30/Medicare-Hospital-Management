# 🏥 MediCare Hospital Management System

## 📌 Project Overview

MediCare Hospital Management System is designed to organize hospital information and support the management of hospital and emergency services.

## 🎯 Objectives

- 🗄️ Store and manage hospital information.
- 🔗 Connect frontend, backend, and database components.
- 🚑 Support hospital and emergency service management.
- 🚀 Provide scope for future improvements.

## 🛠️ Technologies Used

- 💻 Frontend: HTML
- ⚙️ Backend: Java and Spring Boot
- 🗃️ Database: MySQL
- 🔧 Tools: Eclipse, MySQL Workbench, GitHub

## 📂 Project Structure

- 📁 frontend — contains `index.html`
- 📁 backend — contains Java source code and `pom.xml`
- 📁 database — contains `hospital_emergency_db.sql`

## 🚀 Setup Instructions

### 🗄️ Database Setup

1. Open MySQL Workbench.
2. Connect to your MySQL server.
3. Open `database/hospital_emergency_db.sql`.
4. Execute the SQL script.

### ⚙️ Backend Setup

1. Import the backend as a Maven project in Eclipse.
2. Configure the database connection.
3. Run the Spring Boot application.

### 💻 Frontend Setup

1. Open `frontend/index.html` in a browser.
2. Start the backend if the frontend uses its APIs.
